Quick Start (Insurance QA/BA Portfolio)

Files:
- 01_User_Stories.csv – write what the system should do
- 02_RTM.csv – link each story to tests
- 03_Test_Plan.md – how you will test
- 04_Test_Cases.csv – exact steps to test
- 05_UAT_Scripts.csv – simple user checks
- 06_Defect_Log.csv – where you log bugs
- 07_Sample_Data_Policies.csv – example policies
- 08_Sample_Data_Claims.csv – example claims
- 09_PowerBI_Sample_Claims.csv – for dashboards
- 10_Postman_Collection_Template.json – API checks

How to use:
1) Start with 03_Test_Plan.md. Read once.
2) Add/adjust stories in 01_User_Stories.csv.
3) Write/extend tests in 04_Test_Cases.csv.
4) Map stories to tests in 02_RTM.csv.
5) Load sample data (07,08) into your sandbox if needed.
6) Run tests. Mark pass/fail and log bugs in 06_Defect_Log.csv.
7) Run UAT with 05_UAT_Scripts.csv.
8) Build visuals in Power BI from 09_PowerBI_Sample_Claims.csv.
9) Optional: import 10_Postman_Collection_Template.json into Postman and set baseUrl.
